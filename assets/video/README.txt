VIDEOS / CLIPS — drop your files here
=====================================
GitHub Pages is fine for SHORT clips. Keep each MP4 small (ideally < 15 MB; the
whole repo should stay under ~1 GB). For longer videos, use YouTube/Vimeo links
instead and I'll embed them.

How to use:
1. Put short clips here, e.g.  assets/video/demo-cell.mp4
2. Tell me WHERE you want each one (hero background, a "See it in action" section,
   a specific project, etc.) and I'll add the <video> player or embed.

Tip: also add a poster image (a still frame) per clip for a clean first paint,
e.g. assets/video/demo-cell.jpg
