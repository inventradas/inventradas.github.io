PROJECT PHOTOS — drop your images here
======================================
1. Put project photos in this folder (JPG / PNG / WEBP). Keep them reasonably sized
   (e.g. 1200px wide, < 400 KB each) for fast loading.
2. In the admin panel (/admin/ → Projects), set each project's "Image" field to:
       assets/img/projects/your-file.jpg
   The photo then replaces the placeholder icon on that project card.

Example names: pick-and-place.jpg, smart-factory.jpg, esp32-platform.jpg
